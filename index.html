How a build runs

Four steps from audit to handover.

The same order on every project, so clients know what happens next and where their budget goes.

  1. 01

    Audit

    Lighthouse and CrUX baselines, a template inventory, and a list of third-party modules that still expect RequireJS.

  2. 02

    Design tokens

    Colours, type and spacing move from Figma into tailwind.config.js, so the theme and the design file stay in step.

  3. 03

    Build

    A Hyvä child theme, Alpine components and compatibility modules, reviewed in small pull requests.

  4. 04

    Measure & hand over

    Core Web Vitals tracked after launch, with a handover doc your in-house team can pick up straight away.
